# CashFlow72 — Master Your Money

**CashFlow72** is a free, responsive financial education website designed to make personal finance easier to understand. It provides interactive financial calculators and practical money-management insights to help users explore investment growth, loan repayments, savings targets, and compound interest.

## Features

- **SIP Return Calculator:** Estimate total investments, potential returns, and projected investment value.
- **EMI / Loan Calculator:** Calculate estimated monthly loan instalments, total interest, and total repayment.
- **Savings Goal Calculator:** Estimate the monthly and daily savings required to reach a financial target.
- **Rule of 72 Calculator:** Approximate how long it may take an investment to double at a given annual return.
- **Financial Literacy Tips:** Explore practical concepts for budgeting, saving, debt management, emergency funds, and inflation.
- **Responsive Design:** Access the website on desktop, tablet, and mobile devices.
- **Interactive Calculations:** Adjust sliders to see estimates update dynamically.
- **No Sign-up Required:** Use the calculators without creating an account.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

The project is implemented as a standalone HTML page and does not require a frontend framework or build process.

## Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/cashflow72.git
   ```

2. Open the project folder.

3. Open `money financial calculator.html` in your web browser.

Alternatively, rename the HTML file to `index.html` before deployment so it can serve as the default page on supported static hosting platforms.

## Deployment

CashFlow72 can be hosted using a static website hosting service, such as GitHub Pages.

To deploy using GitHub Pages:

1. Upload the project files to your GitHub repository.
2. Ensure the main webpage is named `index.html`.
3. Open the repository's **Settings**.
4. Navigate to **Pages**.
5. Select the appropriate branch and root folder as the publishing source.
6. Save the settings and wait for deployment.

GitHub Pages will provide a public website URL after the deployment completes.

## Privacy

The website is designed to perform financial calculations in the browser without requiring user accounts or a backend database. No backend service is included in the supplied project.

The page also loads Google Fonts from an external service, so browser requests to Google may occur.

## Important Disclaimer

CashFlow72 provides illustrative financial calculations and general educational information. Investment returns are estimates, not guarantees. Actual returns, taxes, fees, inflation, loan terms, and market conditions may affect real-world outcomes.

This website is not a substitute for personalized financial, investment, or tax advice.
